API

Types

AbstractDomain

AbstractDomain

Supertype for the bounding region a network is generated in. The concrete domain a NetworkConfig carries selects which construction generate_network runs.

Subtypes: Cube, HalfSphere.

Cube

Cube()

Cube/box domain: the capillary bed is a Voronoi graph over a square footprint of side region_size, extruded into uniform stacked layers. The default domain.

Examples

generate_network(NetworkConfig(domain = Cube()))

HalfSphere

HalfSphere()

Solid-hemisphere domain {x² + y² + z² ≤ R², z ≥ 0} of radius R = sphere_radius: the capillary bed fills a stack of shrinking disks from the flat equatorial face (z = 0, radius R) up to the apex, and the feeding/draining vessels enter through the curved dome surface. On this domain num_layers acts as an upper bound — the effective layer count is limited by the geometry (⌊R / dz⌋ + 1).

Examples

generate_network(NetworkConfig(domain = HalfSphere(), sphere_radius = 120.0))

NetworkConfig

NetworkConfig{T}(; kwargs...)
NetworkConfig(; kwargs...)

Parameters controlling generate_network, parametric over the floating-point element type T (default Float64). All keyword arguments have defaults matching the reference idealized network.

Select a non-default precision through the type parameter, e.g. NetworkConfig{Float32}(; num_fibers = 60). The bare NetworkConfig(; kwargs...) form always yields NetworkConfig{Float64} — it cannot infer T from the keywords.

Keyword Arguments

  • num_fibers: target number of Voronoi seed cells; controls capillary mesh density.
  • region_size: side length of the square region the capillary mesh covers (Cube).
  • random_perturbation: stddev of the hex-grid jitter, as a fraction of the grid pitch.
  • num_layers: number of stacked layers the planar mesh is extruded into. On HalfSphere this is an upper bound; the effective count is geometry-limited.
  • layer_spacing_fraction: spacing between extrusion layers, as a fraction of the domain’s characteristic size (region_size for Cube, sphere_radius for HalfSphere).
  • drop_fraction_hex_grid: fraction of horizontal (inter-layer) edges dropped per layer.
  • radius_default_small_vessels: median capillary radius (lognormal location).
  • radius_stddev_small_vessels: lognormal shape parameter of the capillary radius.
  • scale_factor_venule: multiplies every venule radius.
  • scale_factor_arteriole: multiplies every arteriole radius.
  • domain: the bounding region, an AbstractDomain (Cube default or HalfSphere); selects which construction generate_network runs.
  • sphere_radius: hemisphere radius R, used only on the HalfSphere domain.

Examples

cfg = NetworkConfig(num_fibers = 60, num_layers = 25)
cfg32 = NetworkConfig{Float32}(num_fibers = 60)
dome = NetworkConfig(domain = HalfSphere(), sphere_radius = 120.0)

NodeTag

NodeTag

Boundary role of a network vertex. Determines whether (and what kind of) a boundary condition applies to the node.

  • Interior — interior node, no boundary condition.
  • NoFlow — no-flow boundary; assigned to the top and bottom extrusion layers.
  • Inlet — arteriole inflow node; carries a velocity boundary condition.
  • Outlet — venule outflow node; carries a pressure boundary condition.
  • InletVenule — venule inflow node; carries a velocity boundary condition.

VascularNetwork

VascularNetwork{T}

A 3D vascular network as a graph of line elements, parametric over the floating-point element type T.

Fields

  • vertices: node positions, one SVector{3,T} each.
  • elements: line elements, each an SVector{2,Int} of 1-based vertex indices.
  • radii: vessel radius per element; length(radii) == length(elements).
  • node_tags: NodeTag per vertex; length(node_tags) == length(vertices).
  • bcvalues: boundary-condition value per vertex (velocity or pressure, depending on the tag); length(bcvalues) == length(vertices). Zero for interior nodes.

Functions

generate_network

generate_network([rng], cfg = NetworkConfig()) -> VascularNetwork

Generate a synthetic idealized myocardial microvascular network.

The bounding region is selected by cfg.domain (an AbstractDomain). Both domains share the same construction in four stages:

  1. A jittered hexagonal point set is tessellated and the in-region Voronoi edges form a planar capillary graph.
  2. That graph is extruded into a stacked 3D capillary mesh.
  3. The bounding surfaces are tagged as no-flow boundaries.
  4. Feeding arteriole(s) and a draining venule are appended and connected to the capillary mesh; capillaries feeding the trees are widened.
  5. Capillaries left disconnected from the main network are pruned (see prune_disconnected).

On Cube the footprint is a square and the mesh is a uniform slab; on HalfSphere the footprint is a disk and the mesh fills a dome whose feeding vessels pierce the curved surface.

Pass an rng for reproducible output.

Examples

using Random
net = generate_network(MersenneTwister(0))
net = generate_network(NetworkConfig(num_fibers = 60))
net = generate_network(NetworkConfig(domain = HalfSphere(), sphere_radius = 120.0))

nelements

Number of line elements in the network.

nvertices

Number of vertices in the network.

plotnetwork

plotnetwork(net; kwargs...) -> Figure
plotnetwork!(ax, net; kwargs...) -> ax

Plot a VascularNetwork in 3D: vessels as line segments colored by radius, and boundary nodes highlighted by NodeTag.

These functions are implemented by a package extension and require a Makie backend — load GLMakie (interactive) or CairoMakie (static) before calling them.

Keyword Arguments

  • colormap: colormap for the vessel radii (default :viridis).
  • linewidth: vessel line width (default 1.5).
  • show_nodes: whether to scatter the boundary nodes (default true).

Examples

using GLMakie, IdealizedMicrovasculature
plotnetwork(generate_network())

smooth_network

smooth_network(rng, net; max_tilt = π/9, spacing = nothing) -> VascularNetwork
smooth_network(net; kwargs...) -> VascularNetwork

Return a refined copy of net in which every straight element is replaced by a sampled cubic Hermite curve, giving the vessels an organic, curved shape. Curves are tangent-continuous through pass-through (degree-2) vertices and along the most-collinear pair of elements at each junction (the “through vessel”); the remaining branches take off along their own chord directions. Organic variation comes from small random tilts of the free end tangents, drawn from rng.

The transformation is pure geometric refinement:

  • Original vertices keep their indices (1:nvertices(net)), positions, tags, and boundary values; new sample vertices are tagged Interior with zero BC value.
  • Every sub-element inherits its parent element’s radius.
  • Topology is unchanged — no vertex moves and no connection is added or removed, elements are only subdivided. Elements shorter than spacing stay single straight segments.

Keyword Arguments

  • max_tilt: maximum random tilt angle in radians applied to free end tangents; 0 disables the organic wiggle (default π/9 ≈ 20°).
  • spacing: target sub-element length in world units; each element is split into ceil(length/spacing) pieces. The default nothing uses a quarter of the median element length, growing the element count roughly 4-6×.

Examples

using Random
net = generate_network(MersenneTwister(0))
curved = smooth_network(MersenneTwister(0), net)

toy_network

toy_network(T=Float64; layout=:volumetric, kwargs...) -> VascularNetwork{T}

Build a small, deterministic VascularNetwork shaped like the textbook microcirculation diagram: a single Inlet on the left feeds a bifurcating arterial tree, its 2^generations leaves drain through an anastomotic capillary bed, and a venous tree converges on a single Outlet on the right.

Unlike generate_network it is pure (no rng) and small, and every count, radius, and symmetry is known in closed form — a fixture for testing solvers, exporters, and smooth_network, which supplies the curvature when composed with it.

Along x, a trunk takes the first 15% of extent, the arterial fan the next 25%, and the capillary bed the middle 20%; the venous tree is the mirror image across x = extent/2. Each tree is a binary fan in which every node sits at the centroid of its descendant leaves. The capillary bed is a ladder — arterial leaf k feeds venous leaves k and k+1 — so it closes loops through the trees. Because every rung leans the same way, the network is symmetric under a half-turn about the bed center rather than a pure x-mirror.

Radii follow Murray’s law (r_parent³ = Σ r_child³) up from capillary_radius: the vessel entering a generation-g node has radius capillary_radius * 2^((generations + 1 - g)/3). Murray’s law holds exactly at every tree junction; the leaves at the two ends of each ladder feed only one capillary instead of two.

The inlet (velocity 1e-3) and outlet (pressure 2000) are degree-1 vertices; every other vertex is Interior with a zero boundary value.

Layouts

With n = 2^generations leaves per tree:

  • :volumetric (default) — generations alternate between splitting in y and in z, so the leaves form a 2^⌈generations/2⌉ × 2^⌊generations/2⌋ grid in the y–z plane. The leaf order is a Z-order curve, so a few ladder rungs jump across the grid. 4n vertices and 6n - 3 elements, of which 2n - 1 are capillaries.
  • :flat — the textbook picture: every node in the z = 0 plane, leaves evenly spaced in y at pitch width/n. Counts match :volumetric.
  • :radial — copies of :flat rotated about the x axis onto planes π/copies apart, sharing one inlet, one outlet, and both trunks, whose radius grows by cbrt(copies) to keep Murray’s law at the hubs. 2 * (2 + copies * (2n - 2)) vertices and 2 * (1 + copies * (2n - 2)) + copies * (2n - 1) elements.

Keyword Arguments

  • layout: one of :volumetric, :flat, or :radial (default :volumetric).
  • generations: bifurcations per tree, ≥ 1; each tree has 2^generations leaves (default 3).
  • extent: inlet-to-outlet distance along x (default 200).
  • width: transverse spread of the leaves (default 100).
  • capillary_radius: radius of every capillary, matching NetworkConfig().radius_default_small_vessels by default (2.6).
  • copies: number of rotated copies, ≥ 1; :radial only (default 4).

Examples

using Random
net = toy_network()                                   # 32 vertices, 45 elements
net = toy_network(; layout=:flat, generations=2)
net = toy_network(Float32; layout=:radial, copies=3)
curved = smooth_network(MersenneTwister(0), toy_network(; generations=4))
